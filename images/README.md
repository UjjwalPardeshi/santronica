# Images for the Santronica website

The site currently uses **royalty-free Unsplash photos** (Unsplash License — free for
commercial use, no attribution required). They are professional placeholders; replace
them with photos of YOUR actual products whenever you have them — same filename, drop
it in this folder, done. No code changes needed.

## Images currently in use

|---|---|---|---|
| `pcb-prototype.jpg` | Dark PCB macro | Your best assembled PCB, close-up | "What We Build" card 1 |
| `connected-device.jpg` | Smart lock + mobile app | Your IoT device next to its app/dashboard | "What We Build" card 2 |

| `og-preview.jpg` | PCB macro, 1200×630 | A branded 1200×630 social-share card | Link previews (WhatsApp/LinkedIn/etc.) |

## Replacement tips

- Keep roughly the same aspect ratio: 3:2 (1200×800) for cards, 1200×630 for `og-preview.jpg`.
- JPG for photos, under ~300 KB each (compress at https://squoosh.app).
- Avoid client-confidential silkscreen text or schematics in shots.
- Dark or neutral backgrounds match the site's navy/cyan theme best.

## Still worth adding later

- Team photo (5 members) — builds trust on a services site
- Certification marks you support (CE, UL, FDA, IECEx/ATEX) if usage rights allow
- Client logos for a "Trusted by" strip (with written permission)
